# Triage labels

Canonical roles map directly to these GitHub labels:

- `needs-triage`: requires maintainer evaluation.
- `needs-info`: waiting for more information from the reporter.
- `ready-for-agent`: fully specified and ready for autonomous implementation.
- `ready-for-human`: requires human implementation.
- `wontfix`: will not be actioned.

Use these exact strings whenever a skill refers to a triage role.
